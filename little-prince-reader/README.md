# 小王子英语精读 · Little Prince Reader

一个面向小学、初中生的英语原著精读软件原型，首本书为 *The Little Prince*。

## 当前版本

- 原文精读：英文原文、中文释义、朗读按钮
- 词汇学习：词义卡片与浏览器语音朗读
- 听说读写：跟读、口语回应、阅读理解、写作迁移入口
- IB 方向：围绕观点（Perspective）、关系（Connection）、反思（Reflection）设计开放式问题
- 学习进度：章节进度、词汇掌握、连续学习天数
- 响应式布局：适合电脑、平板和手机浏览器

## 体验

直接打开 [index.html](./index.html)，或使用 GitHub Pages 发布此目录。
