# TrackIt: two-minute prototype demo

Open the live prototype: https://yiwenliu-png.github.io/ESCP-2627DT-B3/

Use Chrome DevTools → Device toolbar → 390 × 844.

## Story to present

1. Operator / Record: select SHP-1042, choose Sample taken, and press Save activity. Explain that this replaces a manual operational entry.
2. Supervisor / Monitor: review delayed shipments, open issues, and inbound congestion. Resolve an open issue.
3. Manager / Dashboard: show updated activity, delay, and issue metrics plus the 7-day and hourly charts.
4. SAP: switch on Simulate SAP offline, record an activity, show Not sent, switch offline off, and press Retry failed events.
5. Use Reset before repeating the presentation.

## What to say

TrackIt is an operational visibility layer, not a replacement for SAP, WMS, QMS, batch records, or quality decisions. Every record in this prototype is fictional and stored locally in the browser.
